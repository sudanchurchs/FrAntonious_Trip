أضف ميزتين جديدتين في لوحة المنظمين المخفية (?admin=true) مع ربط كامل بقاعدة البيانات (Google Apps Script API):

1. إمكانية تعديل اسم أي شخص في لوحة المنظمين وحفظه في قاعدة البيانات:
- بجانب اسم كل فرد في جدول المنظمين (سواء المسجل الرئيسي أو أي مرافق)، أضف زراً صغيراً للتعديل (`✏️` أو "تعديل").
- عند الضغط عليه، يتحول الاسم إلى خانة إدخال نصية (مملوءة بالاسم الحالي) مع زري **"حفظ"** و **"إلغاء"**.
- عند الضغط على "حفظ":
  * تحقق في الواجهة أن الاسم ثلاثي على الأقل (3 كلمات)، وإذا كان أقل أظهر رسالة تنبيه.
  * أرسل طلباً عبر POST إلى `API_URL` باستخدام `headers: { "Content-Type": "text/plain;charset=utf-8" }` بالجسم التالي:
    `{ action: "updateMemberName", secret: ADMIN_SECRET, memberId: member.id, newName: trimmedName }`
  * أظهر مؤشر حفظ سريع على الزر، وعند وصول الرد الناجح (`data.success === true`) حدّث جدول المنظمين فوراً من `data.registrations` وأغلق وضع التعديل.
  * إذا رجع `success: false` اعرض رسالة الخطأ `data.error`.

2. قسم "التحكم في سعة الباصات والمجموعات اللونية" داخل لوحة المنظمين (?admin=true):
- أضف بطاقة منظمة في لوحة المنظمين تعرض السعة الإجمالية لكل باص ولكل قروب لوني (تُقرأ قيمها الأولية من `data.capacities` أو `data.availability.busLimits` و `data.availability.colorLimits` عند تحميل اللوحة):
  * **الباص الأول (`bus1`)** (الافتراضي 50) + عرض عدد المؤكد دفعهم حالياً (`busCounts.bus1`).
  * **الباص الثاني (`bus2`)** (الافتراضي 50) + عرض عدد المؤكد دفعهم حالياً (`busCounts.bus2`).
  * **القروب الأحمر (`red`)** (الافتراضي 25) + عرض المؤكد دفعهم (`colorCounts.red`).
  * **القروب الأزرق (`blue`)** (الافتراضي 25) + عرض المؤكد دفعهم (`colorCounts.blue`).
  * **القروب الأصفر (`yellow`)** (الافتراضي 25) + عرض المؤكد دفعهم (`colorCounts.yellow`).
  * **القروب الأخضر (`green`)** (الافتراضي 25) + عرض المؤكد دفعهم (`colorCounts.green`).
- لكل عنصر من الستة، وفّر:
  * زر **`-`** لإنقاص العدد بمقدار 1، وخانة رقمية قابلة للكتابة المباشرة (مثلاً 50، 51، 52، 60...)، وزر **`+`** لزيادة العدد بمقدار 1.
- أضف زر **"حفظ السعات الجديدة"** أسفل البطاقة:
  * عند الضغط عليه، يرسل POST إلى `API_URL` (`headers: { "Content-Type": "text/plain;charset=utf-8" }`) بالجسم التالي:
    ```json
    {
      "action": "updateCapacities",
      "secret": ADMIN_SECRET,
      "buses": { "bus1": Number, "bus2": Number },
      "colors": { "red": Number, "blue": Number, "yellow": Number, "green": Number }
    }
    ```
  * عند النجاح (`data.success === true`): حدّث `capacities` و `availability` فوراً في الشاشة، وأظهر رسالة تأكيد خضراء: "تم حفظ السعات الجديدة بنجاح".
  * إذا رجع `success: false` (مثلاً حاول المنظم تقليل السعة أقل من عدد الأشخاص المؤكد دفعهم حالياً): اعرض رسالة الخطأ `data.error` بوضوح.

3. تطبيق السعات المحفوظة تلقائياً في صفحة التسجيل (للزوار):
- عند جلب `availability` (عند فتح الصفحة وفي التحديث التلقائي كل 3 ثوانٍ):
  * استخدم السعات الديناميكية `availability.busLimits.bus1` و `availability.busLimits.bus2` للباصات، و `availability.colorLimits[color]` للمجموعات اللونية بدلاً من أي رقم ثابت (50 أو 25).
  * إذا زاد المنظم سعة الباص من 50 إلى 52 مثلاً وحفظها، يظهر الباص متاحاً بمقعدين متبقيين (`50 / 52`) حتى يكتمل العدد الجديد (52)، وعند اكتماله يظهر فوراً `"البص اتملا"`، ونفس الأمر للقروبات اللونية (`"القروب اكتمل"` عند بلوغ السعة المحفوظة).
