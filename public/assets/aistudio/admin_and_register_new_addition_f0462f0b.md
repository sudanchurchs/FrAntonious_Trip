- استخدم نفس صورة/شعار إنستا باي الأخير المستخدم تماماً في بطاقة "ميخائيل إدور" بنفس الحجم والتصميم.
- اكتب تحتها بوضوح:
  * الاسم: فايز فيكتور
  * رقم الهاتف: +201096656853
- عند اختيار المستخدم لهذه البطاقة الجديدة:
  * يتم إرسال البيانات إلى Apps Script بالقيم: `recipient: "fayez"` و `paymentMethod: "instapay"`.
  * يتم توجيه رسالة تأكيد الواتساب تلقائياً إلى الرقم `201096656853` (`https://wa.me/201096656853?text=...`) باسم "فايز فيكتور" وبطريقة الدفع "إنستا باي".
- في لوحة المنظمين (?admin=true):
  * فعّل بند **إنستا باي (InstaPay)** داخل بطاقة حسابات **فايز فيكتور** (أزل أي تعطيل أو إخفاء عنه إن وُجد) ليعرض تلقائياً المبالغ المدفوعة والمطلوبة وعدد الأفراد من `stats.fayez.byPayment.instapay` تماماً مثل بطاقة ميخائيل إدور.

2. أزرار Toggle / Slider Switch مستقلة لإظهار أو إخفاء الإتاحة لكل باص ولكل قروب لوني لحظياً (Real-Time):
- في لوحة المنظمين (?admin=true)، داخل قسم التحكم اللحظي، أضف **6 أزرار Toggle / Slider Switch مستقلة** (مع إبقاء خيار سريع لتفعيل الكل أو إخفاء الكل دفعة واحدة إن أمكن):
  1. **الباص الأول** (`bus1`)
  2. **الباص الثاني** (`bus2`)
  3. **القروب الأحمر** (`red`)
  4. **القروب الأزرق** (`blue`)
  5. **القروب الأصفر** (`yellow`)
  6. **القروب الأخضر** (`green`)
- عند تحميل لوحة المنظمين (`adminData`)، اضبط حالة كل زر من الـ 6 تلقائياً من `data.settings.availabilityVisibility` (`bus1`, `bus2`, `red`, `blue`, `yellow`, `green`).
- عند تغيير أي زر من الـ 6 في لوحة المنظمين:
  * أرسل POST فوراً إلى `API_URL` (`headers: { "Content-Type": "text/plain;charset=utf-8" }`) بالجسم التالي:
    ```json
    {
      "action": "updateSettings",
      "secret": ADMIN_SECRET,
      "availabilityVisibility": {
        "bus1": true/false,
        "bus2": true/false,
        "red": true/false,
        "blue": true/false,
        "yellow": true/false,
        "green": true/false
      }
    }
    ```
  * حدّث الحالة محلياً فور وصول الرد `data.settings`.

3. تطبيق الإظهار والإخفاء اللحظي في صفحة التسجيل (للزوار):
- في المزامنة اللحظية لصفحة التسجيل (`GET ?action=availability` كل 3 ثوانٍ وعند فتح الصفحة)، اقرأ `data.settings.availabilityVisibility` (وفي حال غيابه استخدم `data.settings.showAvailability`).
- طبّق حالة كل عنصر بشكل مستقل تماماً في نفس اللحظة بدون عمل Reload للصفحة وبدون مسح أي بيانات كتبها المستخدم:
  * لكل باص (`bus1` و `bus2`): إذا كان `availabilityVisibility[busKey] === true` تظهر شارة الإتاحة ("متاح" / "غير متاح" / "البص اتملا") وعدد المقاعد المتبقية لهذا الباص؛ وإذا كان `false` تختفي تماماً كلمات الإتاحة وعدم الإتاحة وعدد المقاعد المتبقية من هذا الباص فقط.
  * لكل لون (`red`, `blue`, `yellow`, `green`): إذا كان `availabilityVisibility[colorKey] === true` تظهر شارة الإتاحة ("متاح" / "غير متاح" / "القروب اكتمل") وعدد الأماكن المتبقية لهذا اللون؛ وإذا كان `false` تختفي تماماً كلمات الإتاحة وعدم الإتاحة وعدد المقاعد المتبقية من هذا اللون فقط.
